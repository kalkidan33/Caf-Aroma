# Café Aroma ☕

Welcome to **Café Aroma**, a responsive web application designed for a modern coffee shop. This project showcases the café's brand, story, menu offerings, and contact details with an interactive user experience[cite: 1].

---

## 🌟 Features

* **Home Page (`index.html`)**: Welcoming landing page introducing Café Aroma.
* **About Us (`about-us.html`)**: Highlights the history, coffee origins, and passion behind the café[cite: 1, 2].
* **Menu (`menu.html`)**: Displays the full selection of drinks, treats, and specialties[cite: 1, 2].
* **Contact (`contact.html`)**: Easy way for customers to reach out or find opening hours[cite: 1, 2].
* **Responsive Design (`style.css`)**: Styled for clean presentation across desktops, tablets, and mobile devices[cite: 1, 2].
* **Interactive Elements (`script.js`)**: Dynamic JavaScript functionalities for enhanced user engagement[cite: 1, 2].
